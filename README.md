# 糸守町 · Itomori

用 **three.js** 程序化重建《你的名字。》中岐阜县糸守町的 3D 场景，按新海诚动画的画面语言来调光影：饱和的天空蓝、带冷色的阴影、逆光的金边、湖面倒影、丁达尔光束和镜头光晕。

整个场景**全部由代码生成**，没有任何外部模型、贴图或电影素材。这是一个非商业的同人致敬作品。

## 运行

```bash
npm install
npm run dev      # 打开 http://localhost:5173
npm run build    # 输出静态站点到 dist/（相对路径，可直接部署到 GitHub Pages 等）
```

需要支持 WebGL2 的浏览器。台式机独显体验最好；手机会自动切换到低画质。

## 场景里有什么

| --- | --- |
| **糸守湖** | 近乎正圆的陨石湖；平面反射 + 程序化涟漪、菲涅尔、浅滩青绿色和太阳碎光 |

| **糸守高中** | 北侧台地上的三层校舍（带时钟塔）、拱顶体育馆和操场跑道 |
| **其他** | 糸守町役场、变电所、翻山而过的高压铁塔、电线杆与下垂的电线、湖岸护栏、栈桥和小船、河上的桥、“咖啡馆”（自动售货机 + 长椅）、塑料大棚、梯田式水田 |

| **天空** | 渐变天穹、卷云、星空与银河、月亮、**提亚马特彗星**（可让碎片分裂）；可被太阳实时重新照明的积雨云 / 积云广告牌 |
| **植被** | 数万棵杉树（多级 LOD）、阔叶树、神社的杉并木、近景的 3D 草丛，全部随风摇动；近处的树用程序绘制的叶片 / 杉针卡片拼成，轮廓像手绘背景 |

### 光影与时间

- 一天中的关键时刻都有手调色板：深夜 → 黎明 → 日出 → 早晨 → 正午 → 午后 → 夕阳 → 夕烧 → **黄昏·片割れ時** → 宵 → 星夜。
- 卡通双色调光照（柔和的明暗交界线）+ 半球环境光让阴影偏蓝紫；树木、建筑有逆光边缘光。
- 跟随太阳方向变色的高度雾（空气透视）：远山逐渐融进地平线颜色。
- 后期：丁达尔光束、彩虹光环与镜头鬼影、Bloom、保色相的色调映射、冷暗部 / 暖高光分离调色、轻微色差、暗角和胶片颗粒。

## 操作

- 鼠标左键拖动旋转，滚轮缩放，右键平移
- `G` 漫步模式：WASD / 方向键在町里散步（Shift 快走），拖动环顾；手机上按住左下角按钮前进
- `1`–`8` 切换镜头：糸守湖全景 · 宫水神社 · 神社远眺 · 町中街道 · 湖畔栈桥 · 鸟瞰 · 御神体 · 糸守高中
- `T` 时间流动 · `C` 自动漫游 · `K` 彗星 · `F` 秋祭灯笼 · `Y` 八年后 / 灾前切换 · `M` 环境音 · `H` 隐藏界面
- 右上角面板：时间滑块、时间预设、彗星分裂等开关，以及“▶ 彗星坠落”

### URL 参数

| 参数 | 作用 |
| --- | --- |
| `?q=low` / `?q=high`（或 `#low`） | 画质。默认会检测显卡：手机、集成显卡和软件渲染用 low，独显用 high；面板里的“流畅画质”可以随时切换 |
| `?t=18.3` | 初始时间（小时） |
| `?shot=hero` 或 `?shot=3` | 初始镜头（id 或序号） |
| `?split=1` | 彗星一开始就是分裂状态 |
| `?era=after` 或 `#after` | 直接打开“八年后”的糸守 |
| `?flow=1` | 时间自动流动 |
| `?comet=0` · `?festival=0` | 关闭彗星 / 灯笼 |
| `?ui=0` | 隐藏界面（截图用） |
| `?debug` | 显示帧率 |

## 代码结构

```
src/
  main.js              入口：渲染器、灯光、加载流程、主循环
  core/
    noise.js           种子随机数、simplex 噪声、fbm / ridged
    era.js             灾前 / 八年后，第二个火口的位置
    materials.js       共享 uniform、卡通光照补丁、空气透视雾（替换 three 的 fog chunk）
    timeofday.js       时间色板关键帧、太阳 / 月亮 / 彗星方向
    shots.js           镜头与自动漫游
  world/
    heightfield.js     湖盆高度场：湖、平地、群山、高中台地、神社山、御神体火口
    layout.js          町的规划：道路、房屋地块、水田、田地，并绘制地面贴图
    terrain.js         以湖为中心的极坐标地形网格（町区域加密），分块剔除
    buildings.js       民家、高中、役场、神社、变电所、铁塔、电线杆、护栏、栈桥……
    builder.js         合并几何体的小工具（一个 draw call 画完全部建筑）
    glow.js            夜间发光材质：窗户、灯笼、路灯、自动售货机
    vegetation.js      杉树 / 阔叶树实例化与 LOD
    foliage.js         程序绘制的叶片图集与卡片树几何体
    grass.js           近景 3D 草丛
    water.js           湖面反射与御神体水沟
  sky/
    sky.js             天穹着色器（渐变、太阳、卷云、星空、月亮、彗星）
    clouds.js          程序化法线贴图积云
  fx/
    post.js            后期管线
    life.js            光尘 / 萤火虫、鸟群
    impact.js          坠落的彗星碎片与光尾
    audio.js           程序化环境音（风、蝉、茅蜩、铃虫）
  ui/ui.js             界面
```

## 说明

- 地形和町的布局参考了电影中糸守的地理关系（圆形湖、北岸高中、山腰神社、东侧河谷、山顶御神体），具体尺寸和建筑细节为再创作，并非逐帧复刻。
- 所有内容由种子随机生成，每次打开都是同一个糸守。
